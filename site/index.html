编辑精选与社区组（6）

归档链

编辑精选

一次 /archive 跑通导出 → 推送 → 检索

成员（安装顺序）

  1. dsh-plugin-transcript会话转录归档：user/assistant/tool 全量落 JSONL → Markdown，接 Obsidian 工作流
  2. dsh-plugin-obsidian-push转录推送 Obsidian 库：frontmatter + 内容哈希幂等去重，vault 自动发现；`/archive` 一键归档链
  3. dsh-plugin-transcript-search跨会话全文搜索，与 transcript 的 JSONL 契约互通
为什么这组（真实握手契约）
  • transcript 产出的 sessions/*.jsonl 是 obsidian-push 与 transcript-search 共同消费的契约文件
  • /archive 串联三家：导出 JSONL → 推送到 Obsidian → 立即可被 transcript-search 检索
装完怎么验
  • dump-config 含三个 id
  • /archive 产出一份 JSONL；/push 能在目标库看到对应笔记；/find 能搜回该会话
/market install archive-chain

开局三件套

编辑精选

先看见钱，再看见所有 IDE，最后能跨窗口派活

成员（安装顺序）

  1. dsh-plugin-quota实时用量仪表 + 下一步预估 + 预算刹车：每回合给模型一行实时 token/花费仪表，模型自己看得见、自己刹
  2. dsh-plugin-ide-hub一个入口管住所有编码 IDE：8 个 IDE 零 API 盘点（含 Trae / Qoder / CatPaw 国产适配）、用量统计、会话一键恢复、规则一份本体多 IDE 下发
  3. dsh-plugin-task-forge把大白话编译成任务书，跨窗口 AI 无损交接：回读握手逼出理解损耗，缺口闭环、版本号跨窗口唯一权威
为什么这组（真实握手契约）
  • task-forge 直接读取 quota 发布的 summary.json 预算契约，派活前先卡预算
  • ide-hub 的 /today 聚合 quota / cost-ledger / task-forge / tool-trace 四家事实，三件套装完即可看到统一视图
装完怎么验
  • dump-config 含三个 id
  • /qm 有输出；/ide-hub 能列出至少 1 个 IDE；/forge 只回显不落盘

省钱组合

编辑精选

同读一份 per-call 成本台账，拦缓存、算预测、对账

成员（安装顺序）

  1. dsh-plugin-cache-guard前缀缓存健康守卫：检测前缀被改写导致的缓存失效多花钱，提醒模型住手
  2. dsh-plugin-spend-forecast按日均消耗预测余量撑几天、几号烧穿
  3. dsh-plugin-cost-ledger花费持久台账：按月 JSONL、月报、CSV 导出、环比结论
为什么这组（真实握手契约）
  • 三家都读 cost-ledger 维护的 per-call token / 成本台账字段，口径一致不打架
  • cache-guard 命中即省一次调用，spend-forecast 直接消费台账算燃烧率
装完怎么验
  • dump-config 含三个 id
  • /health 显示缓存命中；/ledger 有本月汇总；/forecast 与台账口径一致
/market install saving-combo

插件开发

编辑精选

forge 产物过 verify-plugin，cards 负责渲染交付

成员（安装顺序）

  1. dsh-plugin-plugin-forge插件脚手架：生成过 verify-plugin.mjs 的新插件骨架，validate 模式点名现有插件缺什么
  2. dsh-plugin-prompt-optimize提示词审查与改写：8 条本地规则出问题清单，模板重排生成改写稿（vault 存、本插件审）
  3. dsh-plugin-family-cards家族 11 个工具的 web UI 卡片渲染器（补官方 Client 不消费 presentCall 的缺口）
为什么这组（真实握手契约）
  • plugin-forge 的 forgeFiles() 产物必须过 dsh-family-tools/tools/verify-plugin.mjs 的质量门
  • prompt-optimize 改写 /market 入口提示词，family-cards 把结果渲染成家族统一卡片
装完怎么验
  • dump-config 含三个 id
  • /forge 产出插件骨架且过 verify-plugin；/cards 渲染出卡片
/market install plugin-dev

生态雷达

编辑精选

同一套 GitHub 搜索通道与止损规则，先扫后深挖

成员（安装顺序）

  1. dsh-plugin-eco-scandsh 插件生态市场扫描器：topic 全仓 + npm 周下载差值 + 增长评分
  2. dsh-plugin-deep-scanGitHub 赛道深度扫描器：多词四通道搜索 + 自动挖 topic 迭代，止损规则内置
为什么这组（真实握手契约）
  • eco-scan 与 deep-scan 共用 GitHub 搜索通道与搜索止损规则（超时/配额/去重）
  • eco-scan 先出候选仓清单，deep-scan 按同一 repo id 做源码级复核
装完怎么验
  • dump-config 含两个 id
  • /eco-scan 产出候选清单；/deep-scan 对同一 repo id 给出结构清单
/market install eco-radar
